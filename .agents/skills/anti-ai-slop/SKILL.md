# anti-ai-slop

Inspect actual screenshots at desktop/mobile rather than approving code alone. Remove generic gradients, rounded-card repetition, fake logos, generic taglines, fabricated results, gratuitous icons and motion. For each section, identify its narrative goal, evidence and visual focal point. If removing an effect improves comprehension, remove it. Require distinct compositions for hero, projects, journal and about. Check against docs/ART_DIRECTION.md and record specific improvements; do not confuse subjective approval with test results.
