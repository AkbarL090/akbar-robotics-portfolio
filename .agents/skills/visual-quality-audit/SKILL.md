# visual-quality-audit

Run real build and typecheck; test viewport widths 360/390/768/1280/1440/1920, navigation, demos, keyboard, reduced motion, no WebGL, touch, console and network. Save actual screenshots and pointer motion evidence if available. Inspect crop, hierarchy, overflow, contrast, loaded assets and scroll behavior. Measure performance only in available environment; report exact results and limitations, never invent Lighthouse/FPS. Keep originals/certificates private, provide source zip, README and QA report. Fix failures and rerun; no unapproved deployment.
