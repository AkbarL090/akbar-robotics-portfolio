# motion-design

Define intent, trigger, easing, duration, start/end and fallback for every motion. Use normalized local pointer with damped updates; subtle bounded movement, neutral return and cleanup. Avoid state updates each frame. Use GSAP only for necessary coordinated scroll transitions; native CSS for simple reveals. Stop offscreen effects, support reduced-motion and touch, never hide cursor or trap scroll. Verify via actual pointer/scroll recording and screenshot sequence; report if unavailable.
