# editorial-art-direction

Build two distinct hero composition options with real supplied photo, meaningful type scale, whitespace and visible nav. Use paper/graphite/signal palette with contrast-safe text. Keep real project media dominant; choose crop and caption deliberately. Respect portrait and video resolution. Make project list and journal varied editorial compositions, not repeated cards. Get approval before full implementation.
