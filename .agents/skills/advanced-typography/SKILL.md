# advanced-typography

Choose licensed sans + restrained mono. Define tokens for type, spacing, color, measure and fluid sizes; use CSS clamp only with sensible limits. Keep body measure around 45–75 characters, headings visibly distinct, metadata readable. Test 360px and wide screen; avoid all-caps body and tracking abuse. Check accessible contrast and font loading; use fallback fonts. Do not embed key text in canvas or images.
