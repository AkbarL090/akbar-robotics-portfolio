# robotics-visualization

Use actual robot image plane in real 3D scene; no CAD supplied, no invented backside or 360 view. Cap DPR; lazy-load canvas with photo fallback and semantic controls. Implement accessible conceptual goalkeeper field with labeled illustrative thresholds (not actual code) and optional keyboard controls. Inclination demo: normal orientation relative to reference vertical; handle zero/invalid vectors, distinguish geometry from actual RANSAC. Localization diagrams show uncertainty concept, not live data. Cite actual asset and label simulations; do not fabricate measurements.
