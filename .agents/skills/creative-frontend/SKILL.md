# creative-frontend

Use semantic HTML, accessible navigation and keyboard focus, stable URLs for detail pages, local asset manifest, and responsive image variants. Use component abstractions for repeated behavior rather than repeated design cards. Check runtime compatibility, lockfile, typecheck, build and actual navigation. No unnecessary backend, package bloat, fake links or UI-only nonworking controls. Preserve normal scroll.
